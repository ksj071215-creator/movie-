# 🎬 MOVIE FLIX - 넷플릭스 UI/UX 클론 코딩

넷플릭스(Netflix)의 메인 화면 구성을 모티브로 제작한 반응형 영화 정보 소개 웹 애플리케이션입니다.

## 🔗 배포 사이트
👉 [MOVIE FLIX 바로가기](https://ksj071215-creator.github.io/movie-/)

## 🛠️ 사용 기술
- **Frontend**: HTML5, CSS3 (Grid / Flexbox 반응형), Vanilla JavaScript
- **Tools & Deploy**: VS Code, GitHub Pages

## ✨ 주요 구현 기능
1. **히어로 섹션 & 반응형 카드 그리드**: PC와 모바일 등 화면 너비에 맞춰 추천 영화 카드가 자동으로 정렬됩니다.
2. **상단 네비게이션 화면 전환**: `홈`, `영화`, `보관함` 탭 클릭 시 해당 섹션으로 화면이 전환됩니다.
3. **영화 상세 정보 모달 & 찜하기 유지**: 영화를 클릭하면 줄거리와 메타 정보를 팝업으로 확인할 수 있으며, `localStorage`를 연동해 새로고침 후에도 찜한 보관함 목록이 유지됩니다.
